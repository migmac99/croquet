Settings

Configure Synq Manager behavior and features

Synchronizer Registration

Allow synchronizers to self-register via the /synchronizers API endpoint. When enabled, synchronizers can report their status and location to appear on the World Map.

Require API Key

Require a valid API key for session creation. When disabled, clients can create sessions without authentication.

Max Sessions Per Synchronizer

Maximum number of sessions allowed per synchronizer. Set to 0 for unlimited.

About Settings

Settings are stored in Cloudflare KV and apply globally. Changes take effect immediately.
